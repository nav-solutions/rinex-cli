Report
======

The CGGTTS report presents the tracks, the navigation solutions, then the signal combinations
of the receiver (Geometry Free, Ionosphere Free and code multipath, per constellation, see
[signal combinations](../../documentation/Combinations.md)), and the quality control of the
observations. `cggtts --no-combinations` removes the signal combinations.
